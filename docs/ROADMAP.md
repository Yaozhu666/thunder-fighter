# 雷鹰战机 · 版本升级路线图（v2.1 → v10.0）

> 制定于 v2.1 之后。原则：每个大版本一个主题、可独立游玩、可独立回滚（一版一 commit）。
> 难度基线：v2.1 的水滴自爆机削弱后为准，新内容围绕"威胁多样化"而非单纯数值膨胀。

| 版本 | 主题 | 核心内容 | 主要落点 |
|---|---|---|---|
| v3.0 | 精英机与新弹幕 | 新增精英机（高血悬停、必掉道具）；敌弹新增蛇形弹（横向摆动）与加速弹 | entities.js 敌机/子弹、game.js 波次预算与掉落 |
| v4.0 | 僚机系统 | O 道具召唤僚机（最多 2 架），跟随玩家自动射击；坠机损毁 1 架，Boss 通关清空 | Player、PowerUp、掉落表 |
| v5.0 | 能量必杀 | 击杀积攒能量槽，满 100 可放「雷霆风暴」竖向穿透激光（清弹+持续伤害）；E 键 / 触屏长按释放 | Player、game.beam、HUD 能量条 |
| v6.0 | 中场 Boss 与事件波 | 第 3/8/13…关（stage%5==3）第 2 波为中场 Boss（3 种，必掉武器道具）；事件波：陨石雨 / 蜂群包围 | MINI_TYPES、nextWave、Enemy(meteor) |
| v7.0 | Boss 二阶段与新 Boss | Boss 血量 <55% 进入二阶段（弹幕加量提速+外形变化）；新增天罚 WRATH、蜂巢 HIVE（会召唤小蜂） | BOSS_TYPES、Boss.fire/draw |
| v8.0 | 被动芯片 | G 磁力芯片（吸附道具 12s）、C 暴击芯片（玩家子弹 12% 双倍伤害，显示"会心"） | Bullet.crit、PowerUp 吸附、掉落表 |
| v9.0 | 难度选择 | 轻松/标准/炼狱三档：敌弹速、敌机射速、掉率、得分倍率、血量系数；标题界面选择并记忆 | DIFFS、spawnBullet/掉落/计分挂钩、标题 UI |
| v10.0 | 成就·连击·终极 Boss | 连击系统（2 秒窗口加分）、8 项成就（localStorage 持久化+横幅提示）、第 25 关最终 Boss「蚀日·真形态」、结算页统计增强 | combo、ACHS、PRIME cfg、结算 UI |

## 版本节奏约定
- 大版本号：功能主题升级（vX.0）；平衡性修复用 vX.0.Y。
- 每版必做：`node --check` 语法检查 → 浏览器实测新功能（页面内 JS 探针逐帧验证，见踩坑 #53/#55）→ README 验证记录 → 项目仓库 commit。
- 每版掉落表总掉率控制在 43%~50%，避免稀释 P（火力）的成长节奏。
- Boss 通关重置原则（v2.0 确立）：武器/僚机/火力重置，生命/护盾/炸弹保留。
