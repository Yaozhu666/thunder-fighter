## 6. 实测中发现并修复的问题（回写全局日志 #62/#63）
1. **刷新竞态误杀（严重，端到端复现）**：`sendBeacon('/shutdown')` 在页面卸载时异步排队，可能**晚于**
   新页面 reload 的 `/ping` 到达服务器（实测晚 13~18ms）；beacon 晚到后 `shutdown_at` 被重新排程，
   而新页面已 ping 过不会再 ping → 4s 后看门狗退出（刷新误杀）。修复：`main.js` 页面常驻期间**定时保活**
   （`setInterval(fetch('/ping'), 2000)`，间隔 < 服务端宽限 4s），竞态下下一次定时 ping 即取消待退出。
   修复后 reload 6s 服务器存活、关页 4s 退出均实测通过。
2. **切人难度按钮不同步（缺陷）**：`refreshProfile()` 恢复当前玩家难度（含 HUD 标签）但未更新标题界面
   难度按钮 `active` 高亮（该态只在点击与首次加载时设置）→ 切回玩家1 按钮仍停在上一位玩家的炼狱。
   修复：`main.js` 新增 `syncDiffButtons()`，取名/切 chip 后同步。实测切人按钮正确回 normal/炼狱。
3. **file:// 下 /ping CORS 报错（健壮性）**：file:// 直开时 `fetch('/ping')` 被 CORS 拦截产生 console 报错
   （虽被 catch 不影响游玩）。修复：保活与信标仅在 `http(s)` 协议启用。实测 file:// console 无报错。
4. **测试方法备忘**：`bu.close_tab()` 走 CDP 销毁 target 不触发 `pagehide`，无法用其验证关页杀服；
   需用真实导航离开（`location.href='about:blank'`）才能走 pagehide → sendBeacon 路径。
5. **环境残留**：8765 曾同端口并存 `-m http.server`（0.0.0.0）与 `server.py`（127.0.0.1）双进程，
   请求被分流到旧文件；切换服务器时必须 `netstat` 确认仅剩目标进程。
