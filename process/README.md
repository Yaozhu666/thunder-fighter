# process/ —— 过程文件独立存放区

> 约定：**凡是"开发过程中的产物"一律放这里**，不混入代码目录，也不随意删除。
> 每个子目录一个用途，进目录自带说明；新增过程文件先建对应说明再放文件。

## 目录
- `screenshots/` —— 各版本浏览器实测截图（命名 = 版本-场景）
- `probes.md` —— 页面内逐帧探针范式（可复现的自动化测试骨架，附踩坑索引）

## 规则
1. 截图类命名 `v<版本>-<场景>.png`，原文件名无法辨认的归档为 `原始测试帧-*.png` 并写明来源（本区前 16 张均为 2026-09-03 v2.1~v4 实测期间 IAB 截图，含部分验证过程中的结算界面帧）。
2. 过程文件不进 README/CHANGELOG 主文档；有价值的方法沉淀写 `probes.md`，更通用的再回写全局踩坑日志。
3. 清理策略：**只归档有价值的过程产物**（截图、探针脚本、方案草图）；纯垃圾（临时调试输出）直接删，不必保留。
