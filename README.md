# 雷鹰战机（Thunder Hawk）

雷霆战机风格的竖版飞行射击游戏。纯 HTML5 Canvas + 原生 JavaScript，**零依赖、零外部资源**（图形全部 Canvas 路径绘制，音效全部 WebAudio 实时合成）。

> 完整版本变更明细见 [CHANGELOG.md](CHANGELOG.md)，升级路线规划见 [docs/ROADMAP.md](docs/ROADMAP.md)，开发过程文件见 [process/](process/README.md)。

## 目标

- 复刻雷霆战机核心手感：自动射击、弹幕闪避、火力成长、Boss 战
- 武器种类可切换：火神炮 / 散弹 / 追踪导弹，各有 5 级威力（v2.1）
- 成长系统：僚机（v4.0）、能量必杀（v5.0）、磁力/暴击芯片（v8.0）
- 关卡内容：精英机（v3.0）、中场 Boss 与事件波（v6.0）、Boss 二阶段（v7.0）、终极 Boss（v10.0）
- 难度三档（v9.0）与连击/成就系统（v10.0）
- 关卡无限循环、难度递增，越打越难

## 运行

方式一（推荐）：项目内已带启动命令（v12.0 起**关页即退出**——关闭游戏页面，服务器自动关闭端口）

```
cd src
python server.py
# 浏览器打开 http://localhost:8765/（可用端口参数：python server.py 8766）
```

方式二：直接双击 `src/index.html` 也可运行（单页面应用，无跨域资源；无第 1 种方式的关页自毁行为）。

## 系统设计

### 玩家档案（v12.0）
- 标题界面输入玩家名（回车或「确定」），一个名字 = 一个玩家，无密码；最多 6 个档案，点击名字切换
- 每玩家独立存储：最高分、成就、累计战绩（出战/击落/最远关卡）、难度（`th_best_名字` 等键）；
  静音/震动仍为设备级全局设置
- 旧版匿名存档（v11 及以前）首次加载自动迁移为默认玩家「玩家1」；页面刷新不掉档案

### 关卡（v2.0）
- **常规关 = 2 个快节奏波**（较 v1 的 3 波总量少 1/3，过关更快），波间缓冲 1.8s
- **每 5 关一个独立 Boss 关**（第 5/10/15…关），整关只有 Boss，无杂兵
- **中场 Boss（v6.0）**：第 3/8/13…关（stage%5==3）的第 2 波，3 种轮换（哨戒艇/蜂后/掠夺者），
  血量 110~150，击破 +150×关卡数 并必掉 护盾+武器道具，**不掉关**；蜂后会召唤小蜂
- **事件波（v6.0）**：常规第 2 波 28% 概率替换为「陨石雨」（8+N 块坠落陨石，不掉落）或「蜂群包围」（14 连小蜂）
- 关卡无限，常规关强度 `1 + (N-1)×0.22`
- 通关奖励 `500 × 关卡数`
- **通过 Boss 关后武器重置**：火力回 1 级、种类回归火神炮（生命/护盾/炸弹保留）——v2.0 核心，v2.1 扩展

### 武器（v2.1）
三种武器共享火力等级 1~5（坠机掉 1 级，Boss 关通关清零）：

| 道具 | 武器 | 特点 | 弹幕（按等级成长） |
|---|---|---|---|
| V | 火神炮 | 默认直射，均衡 | 1→7 路平行/斜射弹，射速最快 |
| W | 散弹 | 宽角扇面，清杂兵 | 3→9 发扇形（±0.28→±0.58 rad），覆盖广 |
| M | 追踪导弹 | 自动索敌，指哪打哪 | 1→6 发限速转向导弹，射速最慢 |

切换规则：拾取**同类**武器道具 = 火力 +1（满级 +100 分）；拾取**异种** = 切换武器（保留火力等级）。HUD 右下角显示当前武器与等级。

### 敌机（5 种，v3.0）
- 小蜂 bee：正弦下压编队，会打瞄准弹（1×2 血）
- 侧翼机 wing：斜切往返，瞄准双连弹（3 血）
- 自爆机 kamika：**水滴外形**（尖朝上、脉动白核），加速冲撞玩家（4 血）；v2.1 削弱速度——最高速 640→400、加速 260→110 每秒
- 重炮机 heavy：缓慢往返，5 发扇形弹（9 血）
- 精英机 elite（v3.0）：金色中型舰，下压至悬停线后巡航，交替发射**蛇形弹**（横向余弦摆动）与**加速弹**（纵向越飞越快），24 血带血条，**击杀必掉道具**（150 分）

### 僚机（v4.0）
- O 道具召唤无人机（最多 2 架），跟随机身两侧自动射击（青色小弹，0.24s/发）
- 坠机损毁 1 架；**通过 Boss 关全部清空**（跟随武器一起重置）

### Boss（10 种，按 Boss 序号循环 + 强化）
| # | 名称 | 特点 |
|---|---|---|
| 1 | 无畏级 DREADNOUGHT | 扇形/环形/瞄准三连，标准舰 |
| 2 | 迅猛号 RAPTOR | 高速移动，瞄准连射 |
| 3 | 九头蛇 HYDRA | 双侧炮塔螺旋弹 |
| 4 | 移动要塞 FORTRESS | 大体型，环形+随机弹雨 |
| 5 | 幻影 PHANTOM | 极速移动，瞄准+弹雨 |
| 6 | 泰坦 TITAN | 最大体型最高血量 |
| 7 | 漩涡 VORTEX | 螺旋+环形组合 |
| 8 | 蚀日 ECLIPSE | 全弹幕组合+光环特效（终关） |
| 9 | 天罚 WRATH（v7.0） | 瞄准/弹雨/扇形三循环 |
| 10 | 蜂巢 HIVE（v7.0） | 环形+螺旋+弹雨，周期召唤小蜂 |

**Boss 二阶段（v7.0）**：血量 <55% 换形态——扇形/环形弹幕加量（+2/+5 发）、弹速 +15%、冷却 ×0.85，
机体外圈出现旋转尖刺。

第 9 个 Boss 起循环外形，血量 `(320+160×序号差) × hpMul`，弹速每个 Boss +9%（上限 +60%），冷却 -7%（下限 -50%）。血量 <35% 狂暴。

### 道具（掉率 v2.1）
- **P** 火力升级（1→5 级）——掉率 16%
- **W** 散弹 / **M** 追踪导弹 / **V** 火神炮：切换武器，同类拾取升火力——掉率 3.5% / 3.5% / 2.5%
- **O** 僚机（v4.0）：召唤无人机自动射击，最多 2 架——掉率 3%（满编后再拾取 +200 分）
- **G** 磁力芯片（v8.0）：12 秒吸附全场道具——掉率 2.5%
- **C** 暴击芯片（v8.0）：玩家子弹 +6% 概率双倍伤害（显示"会心"），可叠至 20%——掉率 2.5%
- **S** 护盾（挡 1 次伤害，最多叠 3）——掉率 6.5%
- **B** 炸弹 +1（全屏清弹+伤害）——掉率 7%
- **H** 生命 +1（最多 5）——掉率 4%
- 精英机击杀必掉（P/W/M/S/B 加权）
- Boss 掉落固定：护盾 + (炸弹或生命)，不掉武器类（通关即重置，掉了无意义）

### 必杀：雷霆风暴（v5.0）
- 击杀积攒能量：普通敌机 +4、精英机 +12，上限 100（HUD 右下能量条，满时发光）
- 满 100 按 E（或触屏长按 0.45s，移动即取消）释放：竖向穿透激光持续 1.8s
- 激光对带内敌机 60 伤害/秒、Boss 45/秒，并持续清除带内敌弹；释放附带 2.2s 无敌

### 连击与成就（v10.0）
- **连击**：2 秒窗口内持续击杀累计，≥3 显示于 HUD 顶部，≥5 每杀额外 +2×连击 分；坠机或超时清零
- **成就 8 项**（localStorage `th_ach` 持久化）：精英猎手 / 编队司令 / 雷霆初鸣 / 深入敌阵 /
  舰队终结者 / 连击大师 / 十万大名 / 蚀日终结者；解锁时横幅提示，标题界面显示进度，结算页列本局新增
- **终极 Boss（第 25 关）**：蚀日·真形态 PRIME——血量 ×3.2（3072）、全弹幕、大体型光环；
  击落 +2000 分并解锁"蚀日终结者"

### HUD 信息（v11.1）
- **顶部中央**：当前关卡（`第 N 关`）+ 难度档位，常驻显示（此前关卡只在开场横幅出现）
- **底部中央增益栏**：护盾层数、僚机数量、磁力剩余秒数、暴击率——拾取即显示、实时倒计时、耗尽即消失
- 至此所有道具状态均有常驻 UI：P/W/M/V → 右下角武器名+等级；S/O/G/C → 增益栏；B/H → 左下角图标

- 标题界面/结算页显示**累计战绩**：出战局数、累计击落、最远关卡（localStorage `th_stats`）

### 设置与性能（v11.3）
- 暂停界面可开关**屏幕震动**（localStorage `th_shake` 记忆）
- 炸弹新增全屏冲击波圆环；粒子数量上限 420（防弹幕+爆炸叠加时掉帧）
- Boss 血条入场滑入动画

### 氛围与手感（v11.2）
- 画面四角暗角（预渲染贴图，零每帧开销）、背景流星点缀
- 生命 ≤1 时全屏边缘红色脉冲（结算界面自动消退）

### 体验打磨（v11.0，无新玩法）
- **页面切走自动暂停**（visibilitychange），回来点继续或按 Enter
- **静音系统**：M 键 / HUD 按钮，状态持久化（`th_mute`）
- **HUD 状态反馈**：生命 ≤1 红色闪烁、炸弹 0 灰显、能量满时能量条脉冲、道具落出屏幕前闪烁提醒
- **暂停界面**：显示本局得分/关卡/最高连击 + 快捷键速查
- **快捷键**：Enter 在标题/结算界面直接开局，暂停中继续
- 标题界面显示版本号；静态资源加 `?v=` 缓存戳（避免浏览器缓存旧代码）

### 表现
- 三层视差星空、粒子爆炸、屏幕震动、受击红闪、炸弹白闪
- WebAudio 合成音效：射击/爆炸/拾取/Boss 警报/炸弹（无音频文件）
- 最高分 localStorage 持久化（键 `th_best`）

## 结构

```
src/
  index.html        入口 + HUD + 界面层（标题/暂停/结算）
  server.py         v12.0 本地服务器：静态服务 + 关页自毁（/shutdown 看门狗 + /ping 保活）
  css/style.css     界面样式
  js/audio.js       WebAudio 合成音效引擎
  js/profile.js     v12.0 玩家档案（名字=玩家，按玩家隔离存储与迁移）
  js/entities.js    实体类：玩家/子弹/敌机/Boss(10种配置)/道具/粒子
  js/game.js        主循环/关卡系统/碰撞/渲染
  js/main.js        缩放适配/输入(键鼠触)/UI 绑定/状态机
CHANGELOG.md        完整版本日志（v1.0 → v12.0）
docs/ROADMAP.md     升级路线图
process/            过程文件独立存放（测试截图 / 探针范式）
```

逻辑分辨率 480×720（2:3），按窗口等比缩放，devicePixelRatio 高清渲染。

## 已知边界

- 沙箱测试时 IAB 标签页跨轮次会被释放，属浏览器环境行为，与游戏无关
- file:// 直开时 localStorage 在个别浏览器隐私模式下被禁用，存档功能静默降级（不影响游戏）
- **关页自毁边界（v12.0）**：页面常驻期间每 2s 定时保活（/ping），**只要任一页面存活服务器就不退出**；
  仅当**全部**页面关闭（正常关闭触发 pagehide → sendBeacon）后 4s 退出；强杀浏览器进程/断电不走信标，
  服务器残留（手动结束进程即可）——关页自毁对"正常关闭页面"生效。多标签同时游玩互不干扰。
