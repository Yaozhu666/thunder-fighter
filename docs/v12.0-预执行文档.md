## 5. 风险与回滚
- **多标签互杀**：同时开两个页面，关任一都会发 /shutdown（设计如此，README 已注明边界）；测试只开单页
- **强杀浏览器/断电**：不走 pagehide，服务器残留 → 手动结束进程即可（无害）
- **回滚**：`git revert <v12 commit>`（若已提交）；代码在提交前回滚 = 恢复工作树后重做
- **执行期间注意**：8765 工作树已是 v12 文件，刷新即加载新代码——若需中途保留 v11.4 稳定版，先
  `git checkout d1b4ea9 -- src` 并延迟 A 步骤
