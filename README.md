# project-002-thunder-fighter · 雷鹰战机（Thunder Hawk）

雷霆战机风格的竖版飞行射击游戏。纯 HTML5 Canvas + 原生 JavaScript，**零依赖、零外部资源**（图形全部 Canvas 路径绘制，音效全部 WebAudio 实时合成）。

## 目标

- 复刻雷霆战机核心手感：自动射击、弹幕闪避、火力成长、Boss 战
- 关卡无限循环、难度递增，越打越难

## 运行

方式一（推荐）：项目内已带启动命令

```
cd src
python -m http.server 8765
# 浏览器打开 http://localhost:8765/
```

方式二：直接双击 `src/index.html` 也可运行（单页面应用，无跨域资源）。

## 系统设计

### 关卡（v2.0）
- **常规关 = 2 个快节奏波**（较 v1 的 3 波总量少 1/3，过关更快），波间缓冲 1.8s
- **每 5 关一个独立 Boss 关**（第 5/10/15…关），整关只有 Boss，无杂兵
- 关卡无限，常规关强度 `1 + (N-1)×0.22`
- 通关奖励 `500 × 关卡数`
- **通过 Boss 关后武器重置为 1 级**（生命/护盾/炸弹保留）——v2.0 核心改动

### 敌机（4 种）
- 小蜂 bee：正弦下压编队，会打瞄准弹（1×2 血）
- 侧翼机 wing：斜切往返，瞄准双连弹（3 血）
- 自爆机 kamika：加速冲撞玩家（4 血）
- 重炮机 heavy：缓慢往返，5 发扇形弹（9 血）

### Boss（8 种，按 Boss 序号循环 + 强化）
| # | 名称 | 特点 |
|---|---|---|
| 1 | 无畏级 DREADNOUGHT | 扇形/环形/瞄准三连，标准舰 |
| 2 | 迅猛号 RAPTOR | 高速移动，瞄准连射 |
| 3 | 九头蛇 HYDRA | 双侧炮塔螺旋弹 |
| 4 | 移动要塞 FORTRESS | 大体型，环形+随机弹雨 |
| 5 | 幻影 PHANTOM | 极速移动，瞄准+弹雨 |
| 6 | 泰坦 TITAN | 最大体型最高血量 |
| 7 | 漩涡 VORTEX | 螺旋+环形组合 |
| 8 | 蚀日 ECLIPSE | 全弹幕组合+光环特效（终关） |

第 9 个 Boss 起循环外形，血量 `(320+160×序号差) × hpMul`，弹速每个 Boss +9%（上限 +60%），冷却 -7%（下限 -50%）。血量 <35% 狂暴。

### 道具（掉率 v2.0.1）
- **P** 火力升级（1→5 级，Boss 关通关即清零重置）——掉率 **18%**
- **S** 护盾（挡 1 次伤害，最多叠 3）——掉率 8%
- **B** 炸弹 +1（全屏清弹+伤害）——掉率 8.5%
- **H** 生命 +1（最多 5）——掉率 4.5%
- Boss 掉落固定：护盾 + (炸弹或生命)，不掉 P（通关即重置，掉 P 无意义）

### 表现
- 三层视差星空、粒子爆炸、屏幕震动、受击红闪、炸弹白闪
- WebAudio 合成音效：射击/爆炸/拾取/Boss 警报/炸弹（无音频文件）
- 最高分 localStorage 持久化（键 `th_best`）

## 结构

```
src/
  index.html        入口 + HUD + 三块界面（标题/暂停/结算）
  css/style.css     界面样式
  js/audio.js       WebAudio 合成音效引擎
  js/entities.js    实体类：玩家/子弹/敌机/Boss(8种配置)/道具/粒子
  js/game.js        主循环/关卡系统/碰撞/渲染
  js/main.js        缩放适配/输入(键鼠触)/UI 绑定/状态机
```

逻辑分辨率 480×720（2:3），按窗口等比缩放，devicePixelRatio 高清渲染。

## 验证记录

### v1.0（2026-09-02）

### v2.0（2026-09-03）

且生命/护盾/炸弹保留、+500 通关奖励、自动进入第 6 关。
节奏调整复盘：v2.0 首版误将"提速"理解为敌机加速导致过难，已回退；
实际提速 = 每关 2 波 + 1.8s 波间缓冲，单位难度与 v1 持平；P 掉率 21%→12% 过狠，
v2.0.1 回调至 18%。

## 已知边界

- 沙箱测试时 IAB 标签页跨轮次会被释放，属浏览器环境行为，与游戏无关
- file:// 直开时 localStorage 在个别浏览器隐私模式下被禁用，最高分功能静默降级（不影响游戏）
